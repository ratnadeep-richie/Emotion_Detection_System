# 😊 Emotion Detection using NLP, TF-IDF & Logistic Regression


## 📌 Project Overview

Emotion Detection is a Natural Language Processing (NLP) project that predicts human emotions from textual input. The application classifies text into one of six emotions:

- 😄 Joy
- 😢 Sadness
- 😠 Anger
- 😨 Fear
- ❤️ Love
- 😲 Surprise

The project utilizes **TF-IDF (Term Frequency-Inverse Document Frequency)** for feature extraction and **Logistic Regression** as the machine learning classifier. The trained model achieves approximately **86% accuracy** on the emotion dataset and is deployed using a responsive **Streamlit** web application.

---

## 🚀 Features of this project

- Real-time emotion prediction
- NLP text preprocessing
- TF-IDF vectorization
- Logistic Regression classifier
- Confidence score display
- Emotion probability distribution
- Interactive Streamlit UI
- Fast prediction using Pickle model loading
- Easy deployment and extensible architecture
